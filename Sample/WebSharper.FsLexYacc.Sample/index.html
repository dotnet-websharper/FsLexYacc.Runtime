WebSharper.FsLexYacc

FsLex/FsYacc lexer and parser runtime for F# in the browser — with WebSharper

Source

This sample runs lexers and parsers generated by fslex and fsyacc entirely in the browser, against the WebSharper proxy for FsLexYacc.Runtime.

JSON parser (Unicode lexer + fsyacc parser)

JsonParser.start JsonLexer.read (LexBuffer<char>.FromString text). The lexer is generated with fslex --unicode, so it uses UnicodeTables and classifies non-ASCII characters through CharUnicodeInfo.GetUnicodeCategory. 

${JsonResult}

Token stream

The same JSON lexer driven directly, reporting each token with its lexeme and Position — LexemeString, StartPos, EndPos, Line and Column. 

${TokenResult}

“Hello” counter (the classic FsLexYacc walkthrough)

HelloParser.start HelloLexer.tokenstream lexbuf counts the occurrences of hello. 

${HelloResult}

ASCII lexer (byte buffer + AsciiTables)

A lexer generated without --unicode reads a LexBuffer<byte> created with FromBytes and interprets AsciiTables. 

${AsciiResult}

LexBuffer and Position API

FromChars, Lexeme, LexemeChar, LexemeLength, BufferLocalStore, and the Position helpers NextLine, EndOfToken and ShiftColumnBy. 

${ApiResult}
